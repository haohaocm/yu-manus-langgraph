## 2. 推荐启动顺序

### A. 实验室（若未在跑）

1. SSH 连接 Tower（见实验室 SSH 文档）。  
2. 先检查占用：`:8000` / `:8001` 及 `vllm` / `serve_bge_embeddings.py`。  
3. **已占用 → 不要杀、不要重启**，直接用。  
4. 都空闲再按文档启动：
   - `start_qwen_vllm.sh` → `:8000`（当前约定：`tp=2`，`gpu_memory_utilization=0.55`，与 bge 同卡共存；见 GPU 记录）
   - `start_bge_embeddings.sh` → `:8001`（默认 `CUDA_VISIBLE_DEVICES=1`）

### B. 本机隧道（Xshell / SSH -L）

至少两条（与以前「只开 Qwen」相比，**多开 bge**）：

```text
18000 → 实验室 127.0.0.1:8000   # Qwen
18001 → 实验室 127.0.0.1:8001   # bge
```

## 3. 配置要点（`.env`）

见仓库根 `.env.example`：

- `OPENAI_BASE_URL=http://127.0.0.1:18000/v1` — Qwen  
- `EMBEDDING_BACKEND=http` — **禁止设 stub**  
- `EMBEDDING_BASE_URL=http://127.0.0.1:18001/v1` — bge  
- `EMBEDDING_MODEL=bge-m3`
- `EMBEDDING_MAX_BATCH` / `EMBEDDING_MAX_CHARS` — 方案 B 后可尝试略增大 batch（如 8～16）；长文本仍宜保守  
- **CA-1 写文件**
  - `MAX_WRITE_BYTES=512000` — 单次写入 UTF-8 字节上限  
  - `WRITE_BACKUP=true` — 覆盖前写 `*.ca1.bak`  
  - 工具：`write_file`（整文件）、`str_replace`（局部替换）；路径须在 `WORKSPACE_ROOT` 内  
  - **默认** `WORKSPACE_ROOT=artifacts/agent_workspace`（勿再用仓库根当默认可写区）；改真实工程时在 `.env` 指定路径  
  - **HITL（CA-6）：** `HITL_ENABLED=true` 时写文件/shell 会先审批（`/stream` 面板或 `GET /agent/hitl/resume`）；依赖 checkpoint  
- **CA-2 终端**
  - `SHELL_TIMEOUT_SEC=60`、`SHELL_MAX_OUTPUT_CHARS=80000`  
  - 工具：`run_shell(command, working_directory=".")`；看结果里的 `exit_code` / `timed_out`  
- **CA-4 Checkpointer（SQLite）+ 任务名片**
  - `CHECKPOINT_ENABLED=true`、`CHECKPOINT_SQLITE_PATH=artifacts/checkpoints/manus.sqlite`  
  - 运行写入由 LangGraph 自动完成；读状态：`GET /agent/threads/{thread_id}`  
  - 任务名片（同库表 `manus_tasks`）：`GET /agent/tasks`、`GET /agent/tasks/{task_id}`；响应含 `task_id`  
  - **说明：** 程序用 Python 自带 sqlite3；CLI 可用 `D:\support\sqlite\sqlite3.exe` 打开上述 `.sqlite`。  
- **IDX-WS 检索范围**
  - `WORKSPACE_ROOT` — Agent 沙箱 / 目标工程根（默认 `artifacts/agent_workspace`；全仓索引对象）  
  - `SEARCH_MODE=workspace`（默认）或 `corpus`（仅 `SEARCH_CORPUS_DIR`，CE-6 Demo）  
  - `SEARCH_IGNORE_DIRS` / `SEARCH_GLOBS` / `SEARCH_MAX_FILE_BYTES` / `SEARCH_MAX_CHUNKS`

本机若开了 Clash 等代理：应用侧 LLM/embedding 已 `trust_env=False`；仍建议 `NO_PROXY=127.0.0.1,localhost`。

### 重建全仓索引（需 bge）

```powershell
# 或 Agent 调用 semantic_search 时带 rebuild=true
```
