# 计划：CA-7 固定题评测集（MVP）

> 状态：🚧 MVP 已跑通首轮 7/7；可继续加题  
> 术语：eval（评测）、fixture（固定题）、pass rate（通过率）

## 背景与目标

用**固定题**回归 Agent 能力：算对？写对文件？HITL 闸？续聊？步数不过爆。  
非目标：完整评测平台、CI 云端、对抗红队。

## MVP 结构

- `evals/ca7/cases.py`：题面 + 断言  
- `evals/ca7/run_ca7.py`：跑离线假模型 + 可选真模型冒烟，打印表  
- 指标：每题 pass/fail；汇总 pass rate；真模型题记录 status/steps/answer 摘要  

请确认方向后可继续加题；本轮按用户要求直接写题并跑一轮。
