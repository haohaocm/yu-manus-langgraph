# 学习路线：从本项目走向 Cursor 类 Agent

> 目标：做一个「能在真实仓库里读、改、跑、测」的 Agent 系统。  
> 现状：已完成 LangGraph ReAct + MCP 工具 + FastAPI（`yu-manus-langgraph`）。  
> 用法：每天打开本文件 + [`待办清单.md`](待办清单.md)；学完的知识沉淀到 [`../knowledge/`](../knowledge/)。  
> LangGraph 闭环收尾（LG-4）学生向顺序：[`LG-4学生向拆解与学习顺序.md`](LG-4学生向拆解与学习顺序.md)。  
> 当前主线 CE-2 拆解：[`CE-2学生向拆解与学习顺序.md`](CE-2学生向拆解与学习顺序.md)。  
> 每日待办（瘦）：[`待办清单.md`](待办清单.md)；已完成另册：[`已完成归档.md`](已完成归档.md)。---

## 0. 原则

1. **少做「又一个聊天 Agent」**，多做「仓库闭环」。  
2. **上下文工程优先**（你已选定）：先检索/组装/压缩，再堆产品壳。  
3. 工具可继续走 **MCP 网关**；代码读写可先本地工具，再挂网关。  
4. 每完成一块：补知识文档 + 更新待办 +（有联调时）写 records。

## 1. 推荐主线（按优先级）

### P0 — 上下文工程（当前优先）

| 能力 | 学什么 / 做什么 | 完成标准 |
|------|-----------------|----------|
| 检索 | grep / 语义检索 / 文件列表 | Agent 能按任务找到相关文件片段，而不是塞全库 |
| 动态发现 | 长输出落盘再读；工具描述不全量塞 prompt | 上下文不随工具数线性爆炸 |
| 组装 | system + 工具 schema + 历史投影 | 每步请求内容可控、可日志复盘 |
| 压缩 | 超长会话摘要，全文可回查 | 长任务不「失忆」，也不无限涨 token |

详细对照：[`../knowledge/Cursor与DeepSeek-Harness上下文工程.md`](../knowledge/Cursor与DeepSeek-Harness上下文工程.md)

**建议练习顺序（上下文工程拆解）：**

1. 给 Agent 增加 `list_dir` / `read_file` / `grep`（本地或 MCP）  
2. 长工具结果写入临时文件，模型只收到路径 + 前 N 行  
3. MCP 工具：静态只给工具名列表，需要时再加载完整 schema  
4. 会话历史：event log 存全量，发给模型的是投影/摘要  

### P1 — 代码 Agent 闭环

| 能力 | 说明 |
|------|------|
| 编辑 | `apply_patch` / 写文件 + 可回滚 |
| 终端 | 带超时、工作目录、退出码回喂 |
| 计划节点 | Plan → 执行 → 根据测试失败再改（LangGraph 多节点） |

### P2 — 可控与可恢复

| 能力 | 说明 |
|------|------|
| HITL | 改文件前预览 diff / 危险命令审批 |
| Checkpoint | LangGraph checkpointer，中断后续跑 |
| 流式事件 | SSE：每步思考/工具/文件变更 |

### P3 — 评测

| 能力 | 说明 |
|------|------|
| 任务集 | 修 bug、加接口、改配置等固定题 |
| 指标 | 改对文件？测试过？步数/耗时 |
| 回归 | 换模型后对比 |

### P4 — 产品壳（可后置）

侧边对话、diff 面板、多会话、多仓库；**不挡主线**。
