# CTX-1 学生向：成熟投影怎么学

> 详细计划：[`plans/2026-11-22-CTX-1-完备投影近窗摘要可回查.md`](plans/2026-11-22-CTX-1-完备投影近窗摘要可回查.md)  
> 代码目录：`app/context/`

## 一分钟版

- **近窗**：最近几步的原文（已有）。  
- **摘要**：更早步骤的压缩版（尚未做）。  
- **可回查**：摘要里留下「文件路径 / 日志编号」，需要时再 `read_file`（尚未做）。

三者合称成熟投影；只做近窗 = 现在的 CE-5 最小版。

## 学习顺序（与计划阶段一致）

1. **A** 会切回合、分近窗/过期  
2. **B** 会给过期内容做「地址簿」指针  
3. **C** 会做滚动摘要（先规则模板，再考虑 LLM）  
4. **D** 接到 `reason` 的组装器  
5. **E** 假模型证明「能根据线索读回原文」  
6. **F** 写 records / knowledge  

## 和大厂的对应

| 概念 | Cursor / Harness 说法 |
|------|------------------------|
| 真相源 | 文件 / session log |
| 投影 | 进模型的派生历史 |
| 可回查 | Summary + recoverable source |

不要把「Cursor 界面上的思考动画」当成全量 log；那往往是展示层。
