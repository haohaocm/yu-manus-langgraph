# 文档目录说明

本目录按用途分成三类，方便每天学习与跟踪进度。

| 文件夹 | 用途 | 放什么 |
|--------|------|--------|
| [`knowledge/`](knowledge/) | **知识文档** | 概念说明、架构对比、LangGraph/上下文工程等「学完能沉淀」的内容 |
| [`development/`](development/) | **开发文档** | 学习路线、待办清单、开发计划、任务拆解 |
| [`records/`](records/) | **运行与测试记录** | 联调结果、测试报告、踩坑复盘、环境启停记录 |

## 建议阅读顺序（每天）

1. [`development/待办清单.md`](development/待办清单.md) — 看今天要做什么  
2. [`development/项目启动清单.md`](development/项目启动清单.md) — 启服务（**Qwen + bge** 双隧道）  
3. [`development/学习路线-Cursor类Agent.md`](development/学习路线-Cursor类Agent.md) — 对照长期路线  
4. 当天相关的 [`knowledge/`](knowledge/) 文章  

未完成事项请写回 **待办清单**，不要散落在聊天记录里。
