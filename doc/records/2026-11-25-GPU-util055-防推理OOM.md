# 记录：Qwen `gpu_memory_utilization` 0.70→0.55（防与 bge 同卡推理 OOM）

**日期：** 2026-11-25

## 现象

方案 B（util=0.70）启动与短 chat 冒烟可通过；Agent 较长请求时 GPU1（Qwen worker + bge ~8GiB）推理中 CUDA OOM → engine 挂掉 → 本机 SSE 报 `Connection error.`。死后常留孤儿 worker 占 ~16GiB。

## 处理

- 清理孤儿 vLLM worker  
- `start_qwen_vllm.sh`：`0.70` → **`0.55`**（bak：`start_qwen_vllm.sh.bak.util070.*`）  
- 重载后 GPU1 空闲约 **3.7 GiB**；同文案较长 chat 冒烟通过且进程仍存活  

## 配套脚本

- 测前：`scripts/ensure_env.ps1` / `check_lab_services.sh`  
- 测后：`scripts/stop_env.ps1` / `stop_lab_services.sh`
